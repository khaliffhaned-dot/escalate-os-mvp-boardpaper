# Escalate OS — Board Paper MVP

Governance Intelligence Platform for Malaysia's critical organizations.

Transforms monitoring signals into regulatory action, board-ready briefs, and auditable outcomes.

## Stack
- Next.js 15 + React 19
- Tailwind CSS
- OpenNext + Cloudflare Workers

## Run locally
```bash
npm install
npm run dev
```

## Deploy
```bash
npm run deploy
```
